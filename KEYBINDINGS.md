# Keybindings Reference

Mod: `SUPER`

## Applications

| Key | Action |
|---|---|
| `SUPER + Return` | Alacritty |
| `SUPER + SHIFT + Return` | Kitty |
| `SUPER + Space` | Rofi launcher |
| `SUPER + B` | Brave |
| `SUPER + E` | PCManFM |
| `SUPER + V` | Clipboard history |
| `SUPER + ALT + C` | cmus |
| `SUPER + ALT + R` | Random wallpaper |
| `SUPER + W` | Rofi window switcher |

## Window Management

| Key | Action |
|---|---|
| `SUPER + Q` | Close window |
| `SUPER + F` | Toggle fullscreen |
| `SUPER + S` | Toggle floating |
| `SUPER + P` | Toggle pseudo tiling |
| `SUPER + M` | Toggle split layout |
| `SUPER + H` | Focus left |
| `SUPER + J` | Focus down |
| `SUPER + K` | Focus up |
| `SUPER + L` | Focus right |
| `SUPER + SHIFT + H` | Move window left |
| `SUPER + SHIFT + J` | Move window down |
| `SUPER + SHIFT + K` | Move window up |
| `SUPER + SHIFT + L` | Move window right |
| `SUPER + ALT + H` | Resize shrink width |
| `SUPER + ALT + J` | Resize grow height |
| `SUPER + ALT + K` | Resize shrink height |
| `SUPER + ALT + L` | Resize grow width |

## Floating Window

| Key | Action |
|---|---|
| `SUPER + SHIFT + left` | Move floating left |
| `SUPER + SHIFT + down` | Move floating down |
| `SUPER + SHIFT + up` | Move floating up |
| `SUPER + SHIFT + right` | Move floating right |
| `SUPER + mouse:272` | Drag floating |
| `SUPER + mouse:273` | Resize |

## Workspaces

| Key | Action |
|---|---|
| `SUPER + 1..0` | Switch to workspace 1-10 |
| `SUPER + SHIFT + 1..0` | Move window to workspace 1-10 |
| `SUPER + Tab` | Previous workspace |
| `SUPER + [` | Previous workspace (cycle) |
| `SUPER + ]` | Next workspace (cycle) |
| `SUPER + mouse_down` | Next workspace |
| `SUPER + mouse_up` | Previous workspace |

## Scratchpad

| Key | Action |
|---|---|
| `SUPER + I` | Toggle special (hidden) |
| `SUPER + SHIFT + I` | Move to special (hidden) |
| `SUPER + grave` | Toggle special (magic) |
| `SUPER + SHIFT + grave` | Move to special (magic) |

## System

| Key | Action |
|---|---|
| `SUPER + R` | Reload Hyprland |
| `SUPER + SHIFT + X` | Lock screen |
| `Print` | Full screenshot |
| `SUPER + SHIFT + S` | Area screenshot |

## Media (locked)

| Key | Action |
|---|---|
| `XF86AudioRaiseVolume` | Volume +5% |
| `XF86AudioLowerVolume` | Volume -5% |
| `XF86AudioMute` | Toggle mute |
| `XF86AudioMicMute` | Toggle mic mute |
| `XF86MonBrightnessUp` | Brightness +5% |
| `XF86MonBrightnessDown` | Brightness -5% |
| `XF86AudioNext` | Next track |
| `XF86AudioPause` | Play/pause |
| `XF86AudioPlay` | Play/pause |
| `XF86AudioPrev` | Previous track |

## Cheat Sheet (All SUPER Chords)

```
SUPER + ──────────────────────────────────────────────────
  Return    Terminal           Q     Close
  B         Brave              F     Fullscreen
  E         File Manager       S     Toggle float
  V         Clipboard          P     Pseudo
  W         Window switcher    M     Toggle split
  Space     App launcher       R     Reload
  Tab       Last workspace     X     Lock screen
  I         Scratchpad         H/L   Focus
  [ / ]     Cycle workspace    J/K   Focus
  grave     Magic scratchpad

SUPER + SHIFT + ──────────────────────────────────────────
  Return    Kitty              S     Area screenshot
  H         Move left          I     Move to scratchpad
  J         Move down          X     Lock screen
  K         Move up            grave Move to magic
  L         Move right

SUPER + ALT + ────────────────────────────────────────────
  C         cmus               H     Resize shrink
  R         Wallpaper          J     Resize grow down
                               K     Resize shrink
                               L     Resize grow
```
